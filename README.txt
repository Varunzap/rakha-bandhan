RAKSHA BANDHAN — NEAT SINGLE-FOLDER WEBSITE

Open index.html in any modern browser.

Files:
- index.html
- style.css
- script.js
- brother-sister.png

Flow:
1. Premium Raksha Bandhan intro
2. Minimal "Click to Open"
3. Animated greeting + brother/sister illustration + Rakhi tying effect
4. Animated sealed letter
5. Final typewriter letter

The final screen has no NEXT button and browser Back is prevented from returning to previous scenes.

For GitHub Pages:
1. Create a public repository.
2. Upload every file in this folder to the repository root.
3. Settings -> Pages -> Deploy from branch -> main / root.
4. Save and open the generated GitHub Pages URL.


PHOTO SETUP
-----------

Keep the filename exactly: YOUR_PHOTO_HERE.png
Recommended: a clear portrait/photo of you and your sister together.
